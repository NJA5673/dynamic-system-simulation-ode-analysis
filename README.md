# Dynamic System Simulation and ODE Solver Analysis

I used MATLAB to simulate three nonlinear dynamic systems: a forced oscillator, a triple pendulum, and a Duffing oscillator. The project explores how different numerical ODE solvers handle system motion and how changes in model parameters affect the resulting behavior.

## What I studied

- Compared fixed-step and adaptive ODE solvers using displacement, velocity, and step-size plots.
- Simulated a triple pendulum and examined its angular motion and solver performance.
- Explored periodic and more complex responses of the Duffing oscillator using time histories, phase plots, and Poincaré maps.

## Repository contents

- `code/` — MATLAB scripts and solver functions.
- `results/` — figures generated from the MATLAB simulations.

## Running the simulations

Download the repository, open MATLAB, and set the Current Folder to `code`. Run `START_HERE` for the first study, `Triple_pendulum_dynamics_analysis` for the triple pendulum, and `nonlinear_dynamics_and_chaos_sim` for the Duffing study. The scripts save figures in `results/`.
